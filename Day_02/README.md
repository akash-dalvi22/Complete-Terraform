# Day 02 - Terraform Resource Example

This folder contains a simple Terraform example for creating resources.

## Purpose
This README is intended for learning and practicing Terraform resource creation.

## Notes
- You can use this folder to create and manage AWS resources with Terraform.
- Make sure to configure your provider credentials before running Terraform commands.
- This example can be used as a starting point when you plan to create resources on GitHub.

## Basic Workflow
1. Initialize Terraform
2. Review the configuration files
3. Plan the infrastructure changes
4. Apply the changes

## Example
```bash
terraform init
terraform plan
terraform apply
```
